# TC1004B.501_Equipo2_Reto
Desarrollar un prototipo (estilo muñequera o brazalete) capaz de adquirir signos vitales sin que el usuario tenga que operar el dispositivo, enviando la información mediante el protocolo IP (Wi-Fi) a la nube/base de datos y mostrándola en un dashboard remoto con un sistema de alertas.
